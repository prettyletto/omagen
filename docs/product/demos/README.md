# Product demos

This directory is the source for the stable product demo material. The current
workflow preview is [`assets/omagen-demo.gif`](../../../assets/omagen-demo.gif),
but it should be reviewed or recaptured for the v2 release.

The final product package should include a short complete walkthrough and
focused clips for the Fast path, In-depth path, Demo, optional full bar, and
recovery. See the [asset checklist](../ASSET-CHECKLIST.md) for the capture
acceptance criteria.

Do not put developer-only test harnesses or live-desktop setup instructions in
this directory. Those belong in `docs/development/`.
