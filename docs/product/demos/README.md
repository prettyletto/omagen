# Product demos

This directory is the source for the stable product demo material. The current
v2 workflow preview is
[`assets/demos/omagen-demo-v2.gif`](../assets/demos/omagen-demo-v2.gif). It is a
30-fps, 960×540 recording of the complete captured workflow and intentionally
preserves the original pacing.

The original MP4 remains the high-quality source recording outside the
repository. Once `v2.0.0` is released, the GIF may move to a GitHub Release
asset if repository size or page performance makes external hosting preferable.

Watch the [complete v2 walkthrough on YouTube](https://youtu.be/juDJe0zWwZI)
using the [v2 walkthrough thumbnail](../assets/social/omagen-walkthrough-thumbnail-v2.png).

The final product package should include a short complete walkthrough and
focused clips for the Fast path, In-depth path, Demo, optional full bar, and
recovery. See the [asset checklist](../ASSET-CHECKLIST.md) for the capture
acceptance criteria.

Do not put developer-only test harnesses or live-desktop setup instructions in
this directory. Those belong in `docs/development/`.
