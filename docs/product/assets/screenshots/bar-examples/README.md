# Bar examples

A small gallery of the Omagen bar direction at different widths, placements,
and information densities. These are product examples intended to show the
range of the bar presentation; they are not a required configuration or a
claim that every layout is available on every Omarchy version.

The captures use the same v2 visual direction as the product walkthrough.
They are kept as narrow source images so the bar geometry remains visible at
its native aspect ratio.
