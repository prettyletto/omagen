# v2 setup walkthrough

This is the curated product screenshot sequence for the v2 setup flow. The
captures were made on workspace 5 from one cyberpunk city source image, using
the In-depth workflow, the Balanced palette direction, and the Glass Blur
Look & Feel preset already used in the product demo.

The session was temporary and reversible. After the final review capture,
Omagen's **Restore & close** action was used; the original wallpaper and
native bar returned, the session became inactive and non-recoverable, and no
Omagen layers remained.

details visible in the raw file chooser and selected-image captures have been
